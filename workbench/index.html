工作区与执行权限
手机目录只列出发消息者自己的工作区，不列出本机私人历史。好友与群成员按聊天名称、成员显示名区分，同名或改名可能影响归属，请使用唯一备注 / 群昵称。群回复对全群可见。
所有好友都能提交本机 Codex 任务。Codex 使用 workspace-write 沙箱；独立目录不等于 Windows 账号隔离，也不限制沙箱允许的文件读取。GPT 账号模式经 Codex 在本次任务的附件目录内写入文件；Muse 个人智能体在云端执行任务，工作台只取回本次任务明确交付的附件。可在联系人列表暂停个别会话。

手机操作说明
/help 查看命令
/status 查看最近任务
/result 取回自己的最近结果
/new 新建上下文
/stop 停止任务
贾维斯个人微信号支持文字和通用文件附件，包括图片、视频、PPT、PDF、表格等。各模型共用附件发送通道；文件须实际生成。当前每个文件最多 100MB、每次 20 个、合计 300MB，微信自身限制仍适用。发送 /result 可取回结果：部分失败只重试未完成附件，全部发送成功后再次取回会重发全部附件。iLink 入口当前只支持文字。WhatsApp 使用其他账号向绑定账号发私聊消息，暂不处理“给自己发消息”。这些消息入口均为社区方案，连接可用性取决于平台接口。
